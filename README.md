# CC Hexa

Виртуальная химлаборатория-песочница для школьников 7–11 классов. Казахский, русский и английский языки.
Проект CC Lab (Code Collective Laboratory). Название рабочее, его можно поменять в `src/ui/TopBar.tsx` (`APP_NAME`).

Сайт: https://cc-hexa.vercel.app (Vercel пересобирает его после каждого push в ветку).

## Что умеет

- Полка из ~95 реактивов: кислоты, основания, соли, оксиды, 17 металлов (от лития до золота), неметаллы (сера, иод, уголь, кремний, хлорная и бромная вода), кристаллы для нагревания, лёд. Количество в миллилитрах и граммах, бытовые сравнения («≈ чайная ложка», «≈ горошина»), карточки веществ (где встречаются в быту, чем опасны).
- Полная школьная таблица растворимости (21 катион × 14 анионов) — из неё движок берёт осадки и их цвета.
- Посуда: пробирки, стаканы на 100 и 250 мл, коническая колба; лишняя жидкость переливается через край, слишком бурная реакция разбивает сосуд (натрий от 0,3 г, калий от 0,2 г; калий горит фиолетовым пламенем).
- Нагрев спиртовкой с настоящей мощностью: большой объём греется дольше, вода кипит (с солью — выше 100 °C), выкипает, оставляя сухой остаток; ускорение времени ×1, ×5, ×20, ×60.
- Физические процессы: растворение с нагревом или охлаждением (селитра, гидроксид натрия), насыщенные растворы и кристаллизация при выпаривании и охлаждении, плавление (сера), возгонка (иод), таяние льда, перегонка через трубку, фильтрование, магнит, окрашивание пламени, адсорбция углём.
- Разложение при нагревании: перманганат калия (кислород), сода, малахит, медный купорос (белеет), нашатырь, селитра, «вулкан» из дихромата аммония; железо + сера, оксид меди + уголь.
- Реакции новых веществ: сероводород и сернистый газ, помутнение тиосульфата (скорость зависит от температуры), галогены вытесняют друг друга, крахмал и иод, хромат ⇄ дихромат, перманганат и дихромат в кислоте, «золотой дождь» иодида свинца, амфотерные гидроксиды свинца, олова, хрома.
- Таблица Менделеева: карточка каждого из 118 элементов на трёх языках — свойства, электронная формула, где встречается (в том числе в Казахстане), опасность.
- Газоотводная трубка в газосборник или в другой сосуд; проба газа тлеющей и горящей лучинкой, влажным лакмусом, известковой водой.
- Титрование: бюретка, кривая титрования, точка эквивалентности, задача «кислота X неизвестной концентрации».
- Электролиз и электропроводность растворов: графитовые электроды, лампочка, медь на катоде, хлор и кислород на аноде.
- Окно «Что произошло»: объяснение, «Почему?», «В жизни», результаты в граммах и миллилитрах, уравнения по классу (7 — словами, 8 — уравнение, 9+ — ионные).
- Таблицы (Менделеев, растворимость, ряд активности, индикаторы), журнал опытов, открытия.
- Аккаунты по никнейму и паролю (без почты), прогресс сохраняется на сервере.
- Админ-панель: `https://cc-hexa.vercel.app/#admin` — посещаемость, аккаунты, опыты, устройства, языки, классы, популярные реакции, роли пользователей.

## Администратор

Зарегистрируйся на сайте, открой профиль (кнопка с ником справа вверху) и введи код администратора.
Код хранится в базе только в виде хэша; если его нужно сменить, запиши новый хэш SHA-256 в таблицу `app_secrets` (`name = 'admin_code'`).

## Запуск

```
npm install
npm run dev      # разработка, http://localhost:5173
npm test         # тесты движка химии и приборов
npm run build    # сборка в dist/
```

## Где что лежит

- `src/engine/` — движок химии без интерфейса: вещества (`data.ts`), правила реакций (`rules.ts`, `rulesMore.ts`), физические процессы (`physics.ts`), уравнения, pH, цвета, приборы (`apparatus.ts`). Тесты рядом.
- `src/data/` — таблица Менделеева и карточки элементов.
- `src/state/lab.ts` — состояние стола: сосуды, трубки, газосборник, бюретка, электролизёр, отмена, журнал.
- `src/i18n/` — все тексты на трёх языках.
- `src/ui/` — интерфейс, `src/ui/Admin.tsx` — админ-панель.
- `src/net/` — связь с базой данных (Supabase). Публичный ключ в `config.ts` можно переопределить переменными `VITE_SUPABASE_URL` и `VITE_SUPABASE_KEY`.
- `supabase/migrations/` — схема базы данных.
- [План проекта](docs/PLAN.md), [вещества и реакции](docs/content-mvp.md)

## Данные и закон

Сохраняются только никнейм, класс, хэш пароля и прогресс; почта, телефон и имя не собираются. Статистика посещений анонимная.
База сейчас находится во Франкфурте (Supabase). По закону РК о персональных данных данные граждан Казахстана должны храниться на территории РК:
перед официальным использованием в школах нужно перенести базу на казахстанский хостинг или получить консультацию юриста.
