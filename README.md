# CC Hexa

Виртуальная химлаборатория-песочница для школьников 7–11 классов. Казахский, русский и английский языки.
Проект CC Lab (Code Collective Laboratory). Название рабочее, его можно поменять.

Сейчас готов этап 1 — минимальная версия: стол с четырьмя пробирками и стаканом, 50 реактивов,
переливание, нагрев спиртовкой, окно «Что произошло» с объяснением и «Почему?», уравнения по классу,
таблицы (Менделеев, растворимость, ряд активности, индикаторы), журнал опытов, две темы, три языка.

## Запуск

```
npm install
npm run dev      # разработка, http://localhost:5173
npm test         # тесты движка химии
npm run build    # сборка в dist/ (работает и без интернета после первой загрузки)
```

## Где что лежит

- `src/engine/` — движок химии без интерфейса: вещества, правила реакций, уравнения, pH, цвета. Тесты в `engine.test.ts`.
- `src/i18n/` — все тексты на трёх языках (`kk.ts`, `ru.ts`, `en.ts`).
- `src/data/elements.ts` — данные таблицы Менделеева.
- `src/state/lab.ts` — состояние стола: сосуды, отмена, журнал, открытия.
- `src/ui/` — интерфейс: полка, стол, панель, окна.
- [План проекта](docs/PLAN.md), [вещества и реакции](docs/content-mvp.md)
- `design/` — макет этапа 0 и логотип (SVG, анимация CC Hexa ↔ CC Lab)
